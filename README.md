# gb-station-data

This is a repo containing data about all GB train stations[^1].

## Installation
You can add this data to your JS/TS project with this command:
```shell
npm add @tangledwires/gb-station-data
```

Or add this to your Gemfile if you're using Ruby:
```ruby
gem "gb-station-data"
```

[^1]: This repo is not complete yet.
